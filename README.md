# Variedades Nora 👜✨

Sitio web oficial de **Variedades Nora**, una tienda de accesorios de moda en Nicaragua enfocada en bolsos, carteras, mochilas, cangureras, cosméticos, maquillaje, cremas, artículos para bebé y accesorios modernos.

El objetivo del sitio es presentar el catálogo de productos, facilitar la consulta de disponibilidad y conectar directamente con los clientes mediante WhatsApp.

🌐 **Sitio web:**  
https://jhernandez30-cpu.github.io/Variedades-Nora/

---

## 📌 Descripción del proyecto

**Variedades Nora** es una tienda digital diseñada para mostrar productos modernos, prácticos y accesibles para clientes en Nicaragua.  
La página permite a los usuarios explorar categorías, revisar productos destacados, conocer promociones, leer preguntas frecuentes y contactar por WhatsApp para consultar precios, colores, modelos y disponibilidad.

El sitio está orientado a mejorar la presencia digital del negocio y facilitar la atención personalizada a clientes interesados en productos de moda y accesorios.
